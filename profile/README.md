# [Modique Project Studios](https://modiqueps.com)

**Modique Project Studios** is a project production studio — not a single product. Modique itself is one of the projects we produce; the studio's scope covers everything we build under it, across any medium or product type.

We prioritize clean architecture, reusable components, and long-term maintainability across every project, rather than treating each one as a one-off.

## What we do

- Produce and maintain multiple independent projects under the studio umbrella
- Develop modular tools and libraries that are reused across ModiquePS projects
- Keep interfaces simple so components can be swapped or extended without rewrites
- Maintain a small, focused codebase per project rather than a sprawling one
